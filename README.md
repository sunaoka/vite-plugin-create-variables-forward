# vite-plugin-create-variables-forward

A Vite plugin that automatically generates `@forward with` from SCSS variables.

## Installation

```bash
# #1.0.0 is the version
pnpm add -D git+https://github.com/sunaoka/vite-plugin-create-variables-forward#1.0.0
```

## Usage

```typescript
// vite.config.ts
import { defineConfig } from 'vite';
import variablesForward from '@sunaoka/vite-plugin-create-variables-forward';

export default defineConfig({
  plugins: [
    variablesForward({
      from: 'src/styles/_variables.scss',        // SCSS file that defines variables
      to: 'src/styles/_variables-forward.scss',  // Generated output file
      module: 'theme',                           // Main module to @forward with overridden variables
      modules: ['other-theme'],                  // Additional modules to @forward (optional)
    }),
  ],
});
```

## How it works

1. Reads the SCSS file specified by `from`
2. Parses all SCSS variables starting with `$`
3. Generates a new SCSS file including:
   - `@use` for the source file as a module
   - `@forward` with variable mappings
   - Optional additional `@forward` modules

## Example

Given `_variables.scss`:

```scss
$primary-color: #ff0000;
$secondary-color: #00ff00;
```

The following will be generated:

```scss
// Do not edit this file manually.
// This file is auto-generated by vite-plugin-create-variables-forward from _variables.scss.
@use 'variables' as var;
@forward 'theme' with (
  $primary-color: var.$primary-color,
  $secondary-color: var.$secondary-color
);
@forward 'other-theme';
```
